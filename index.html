Professional Summary

I build test automation frameworks and quality tooling for software teams. My background is Java-based API and UI automation (RestAssured, Selenium, TestNG), and my current focus is Playwright and AI-assisted testing: using LLMs to generate test code that engineers review and own, rather than trusting it blindly.

Featured Projects

AI Test Automation Generator

A VS Code extension that turns manual test cases into Playwright tests. Engineers review the Claude-generated code, regenerate with feedback, and commit it to GitHub. It reads the target repo's existing fixtures and page objects so output follows the suite's conventions.

Architecture: TypeScript/React extension, FastAPI backend, async Redis (RQ) worker jobs calling the Claude API, PostgreSQL, GitHub OAuth, deployed on Railway.

My role: built the whole stack solo. The generate, regenerate, connect and commit loop is verified end-to-end on the live deployment. No external users yet.
